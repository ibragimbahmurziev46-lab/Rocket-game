

# Public Schedule

Табло расписания занятий колледжа в стиле авиационного табло. Фронтенд — React + TypeScript (Vite), бэкенд — FastAPI. Данные загружаются напрямую из API NewLXP (GraphQL).

## Структура проекта

```text
public_schedule/
├── launch.bat (скрипт для автоматического запуска бэкенда, фронтенда и браузера)
├── update_cache.bat (скрипт для обновления локальной базы студентов)
├── backend/
│   ├── main.py (основной сервер)
│   ├── update_cache.py (скрипт обновления базы студентов)
│   ├── students_cache.json (локальная база групп и ID студентов)
│   └── venv/ (виртуальное окружение)
├── frontend/
│   ├── src/
│   │   ├── App.tsx
│   │   ├── App.css
│   │   └── index.css
│   ├── package.json
│   └── node_modules/ (зависимости)
└── README.md
```

## Установка и запуск

### Способ 1: Автоматический запуск (Рекомендуемый)

В корне проекта создан файл `launch.bat`. Дважды кликните по нему. 
Скрипт автоматически:
1. Откроет терминал для бэкенда и запустит сервер.
2. Откроет терминал для фронтенда и запустит Vite.
3. Подождет 5 секунд и откроет браузер с адресом `http://localhost:5173`.

Для остановки проекта просто закройте оба открывшихся окна терминала.

### Способ 2: Ручной запуск

Проект требует **два параллельно работающих терминала**.

**Терминал №1 — Бэкенд**

Из корня `public_schedule`:

```bash
cd backend
python -m venv venv
```

Активация виртуального окружения:

**Windows (cmd):**
```cmd
venv\Scripts\activate.bat
```

**Windows (PowerShell):**
```powershell
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

Установка зависимостей и запуск:

```bash
python -m pip install fastapi uvicorn requests urllib3
python -m uvicorn main:app --reload --port 8000
```

**Терминал №2 — Фронтенд**

Из корня `public_schedule`:

```bash
cd frontend
npm install
npm run dev
```

Vite выведет адрес (обычно `http://localhost:5173`). Откройте его в браузере.

## Обновление базы студентов

Данные о группах и ID студентов сохраняются в файл `backend/students_cache.json`. Сервер загружает их оттуда при старте, чтобы не делать тяжелые запросы к API каждый раз.

Если в колледже добавились новые группы или студенты, вам нужно обновить этот файл.
1. Дважды кликните по файлу `update_cache.bat` в корне проекта.
2. Дождитесь завершения работы скрипта (появится сообщение об успехе).
3. Перезапустите бэкенд.

## Использование

- Экран показывает текущее время и список предстоящих пар для всех доступных групп.
- Пары, начавшиеся более 10 минут назад, автоматически скрываются (строка «переворачивается», на её месте появляется следующая).
- Каждые 10 секунд выполняется переворот всех строк, синхронизированный с секундами на часах.
- Строка идущей пары помечается статусом `ИДЕТ` в четвёртом столбце.
- Названия аудиторий на русском языке автоматически переводятся на английский (словарь `ROOM_TRANSLATIONS` в `main.py`).

### Тестирование (Mock-данные)

Для отладки фильтрации и просмотра расписания на будущие даты можно подменить текущее время и дату через query-параметры в адресной строке:

```
http://localhost:5173/?mockTime=09:00
http://localhost:5173/?mockDate=2026-11-07
http://localhost:5173/?mockDate=2026-11-07&mockTime=10:25
```

- `mockTime` сдвигает часы на указанное время.
- `mockDate` заставляет бэкенд запросить расписание на конкретный день (формат `YYYY-MM-DD`).

## Возможные проблемы

### 1. PowerShell блокирует npm или активацию venv

**Симптом:**
```
npm : Невозможно загрузить файл ...\npm.ps1, так как выполнение сценариев отключено
```

**Решение A (PowerShell, один раз):**
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

**Решение B:** Используйте cmd вместо PowerShell. В cmd активация venv происходит через `venv\Scripts\activate.bat`, а npm работает без ограничений.

### 2. Бэкенд зависает на строке `=== LOADING GROUPS FROM LOCAL FILE ===`

**Причина:** Файл `students_cache.json` заблокирован другим процессом (открыт в VS Code, Блокноте, или сканируется антивирусом). Python не может его прочитать и бесконечно ждет.

**Решение:** Закройте все редакторы, где открыт этот файл. Если не помогает — перезагрузите компьютер.

### 3. Ошибка 500 от API NewLXP (Кураторский аккаунт)

**Симптом в консоли:** `Ошибка API (milanachutieca52@gmail.com): Что-то пошло не так...`

**Причина:** На стороне сервера колледжа (NewLXP) сломан эндпоинт для получения расписаний кураторами. Код бэкенда использует механизм обхода (опрашивает расписание конкретных студентов), чтобы обойти эту ошибку. Если ошибка все же появляется, подождите или обновите данные о студентах через `update_cache.bat`.

### 4. Таблица пустая

**Причина:** На выбранную дату (сегодня) пар нет, либо все они начались более 10 минут назад.
**Решение:** Используйте параметры `?mockDate=YYYY-MM-DD` (выберите день, когда точно есть пары) и `?mockTime=08:00`, чтобы принудительно отобразить данные на экране.

### 5. Кириллица отображается квадратами или неправильно

**Причина:** Шрифт `Barlow Condensed` подгружается с Google Fonts, нужен доступ к интернету.
**Решение:** Проверьте сетевое соединение.

### 6. Ошибка `ENOENT: no such file or directory, open '...package.json'`

**Причина:** Команда `npm create vite` не выполнилась, папка `frontend` пуста.
**Решение:** Удалите папку `frontend` и создайте заново:
```powershell
Remove-Item -Recurse -Force frontend
npm create vite@latest frontend -- --template react-ts
cd frontend
npm install
```

## Остановка

Если вы использовали `launch.bat` — просто закройте окна терминалов.
Если запускали вручную — нажмите `Ctrl+C` в каждом из двух терминалов.

## Известные ограничения

- Время начала пары берется из API. Длительность пары (80 минут) зашита в `App.tsx` для вычисления статуса "ИДЕТ". Если в колледже есть пары другой длительности, потребуется доработка.
- Для доступа к API используются учетные данные аккаунта, прописанные в `main.py`. При смене пароля потребуется обновить код.
- CORS в `main.py` открыт для всех источников (`allow_origins=["*"]`). Для продакшена — ограничить конкретным доменом.
