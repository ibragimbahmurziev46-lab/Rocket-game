# 🚀 Rocket Lab

**Интерактивный симулятор ракет на Canvas 2D: погоня за курсором с ограниченным топливом и режим стройки с разрушаемыми целями.**

Один requestAnimationFrame-цикл, собственная физика наведения, невесомость, взаимные тараны, синтезированный звук и четыре палитры. Без единой графической ассеты — всё рисуется кодом.

## ⚡ Быстрый старт

Требуется **Node.js 18+** и npm.

```bash
# 1. зависимости
npm install

# 2. дев-сервер с HMR
npm run dev
```

Открой адрес из терминала (обычно `http://localhost:5173`) — сцена уже живая: ракета стартует из случайного края и идёт на курсор.

```bash
# продакшн-сборка
npm run build

# локальный просмотр сборки
npm run preview
```

## 🎮 Режимы

### 🎯 Погоня

Ракета появляется у случайного края экрана и доворачивает **носом** на курсор. Скорость поворота ограничена, поэтому она делает реалистичные дуги, а не телепортируется углом.

**Правила топлива:**

1. Бак измеряется в **секундах работы двигателя** и тратится 1:1 во время полёта.
2. Осталось меньше `1.2 с` — пламя начинает чихать: след реже, частицы мельче, тяга слабее.
3. Бак пуст → звук захлёбывания, клуб пара из сопла, двигатель выключен навсегда.
4. Дальше корпус — **инертный обломок**: он не реагирует на курсор, медленно кувыркается и летит по прямой. Пунктирная линия показывает вектор инерции.
5. Затухание `0` → вечный полёт по направляющей. Затухание `1` → скорость гаснет, корпус **зависает** в невесомости.
6. Обломок исчезает через `wreckLife` секунд, плавно растворяясь в последние `1.2 с`.

**Столкновения:** любые две ракеты — живые, пустые, живая+пустая — взрываются обе. Взрыв усилен (×1.25) и разбрасывает металлические осколки. Счётчик столкновений ведётся отдельно от перехватов.

> Пустой корпус **не** детонирует от касания курсора — он мёртвый. Но он остаётся препятствием: влетевшая в него живая ракета уничтожит обе.

### 🧱 Строитель

Клик по сцене ставит статичный объект. Ракеты автоматически стартуют из случайных точек и поражают цели; бак в этом режиме бесконечный, чтобы цели гарантированно добивались.

| Объект | Размер | HP | Поведение |
|---|---|---|---|
| 🎯 Мишень | 46 × 46 | 1 | Ящик с красно-белой мишенью, разлетается щепками |
| 🧱 Стена (гориз.) | 118 × 28 | 3 | Кирпичная кладка, трещины по мере урона, полоса прочности |
| 🧱 Стена (верт.) | 28 × 118 | 3 | То же, повёрнуто переключателем |
| 🧽 Ластик | — | — | Подсвечивает объект под курсором и удаляет по клику |

**Стены работают как укрытия:** ракета детонирует о **первый** задетый объект, даже если он не был её целью. Поставь стену перед мишенью — и ракета потратит себя на стену.

Выбор цели учитывает очередь: `score = incoming × 600 + distance`. Две ракеты не полетят в одну мишень, пока есть свободные.

## 🔬 Как это работает

### Наведение

```ts
// желаемый курс и фактическая ошибка
const diff = normAngle(Math.atan2(dy, dx) - r.angle);

// вблизи цели ракета манёвреннее (до ×3.4)
const boost = dist < 160 ? 1 + (1 - dist / 160) * 2.4 : 1;
const maxTurn = (agility * Math.PI / 180) * dt * boost;
r.angle = normAngle(r.angle + clamp(diff, -maxTurn, maxTurn));

// в крутом вираже тяга падает — ракета не может «дрифтить» боком
const align = Math.max(0, Math.cos(diff));
const wanted = speed * (0.32 + 0.68 * align);
r.speed += (wanted - r.speed) * Math.min(1, dt * 3.2);
```

Нос нарисован вдоль `+X`, поэтому `ctx.rotate(angle)` всегда ставит его по курсу — ракета никогда не летит боком.

### Невесомость

```ts
const k = Math.exp(-drag * 1.8 * dt);   // кадронезависимое затухание
r.vx *= k;
r.vy *= k;
r.angle = normAngle(r.angle + r.spin * dt);  // медленный кувырок ±0.7 рад/с
```

При `drag = 0` множитель равен 1 — чистая инерция, полёт по прямой бесконечно.

### Столкновения без «протыкания»

На скорости 600 px/с и `dt = 0.05` ракета проходит 30 px за кадр — обычная проверка расстояния пропускает цели. Поэтому используются **отрезковые** тесты:

| Случай | Метод |
|---|---|
| Ракета → объект | Отрезок носа `(prev → current)` против прямоугольника, алгоритм Лианга — Барски (`segRect`) |
| Ракета → ракета | Отрезок **относительного** движения против круга радиусом `BODY_R × 2 × scale` (`segCircle`) |

Взаимные тараны собираются в `Set<number>` и удаляются одним `filter` — индексы массива не ломаются при удалении двух элементов за кадр.

### Взрыв

Три независимых слоя с аддитивным смешиванием:

| Слой | Окно | Радиус | Спад |
|---|---|---|---|
| Вспышка | 0 → 0.15 с | 40 → 200 | линейный |
| Огненное ядро | 0 → 0.35 с | 25 → 115 | `sin(t · π/2)` |
| Ударная волна | 0 → 0.55 с | 15 → 265 | `easeOutCubic` |

Тряска камеры: `shake = max(shake, 24 × power)`, затухание 90 ед/с. Частицы: `80 × power` искр, `30 × power` клубов дыма, щепки дерева при разрушении объекта, металл при таране ракет.

### Бюджет производительности

| Механизм | Значение | Зачем |
|---|---|---|
| Один `requestAnimationFrame` | 1 цикл | Нет дублей при StrictMode и повторных монтированиях |
| `devicePixelRatio` | `min(dpr, 2)` | Retina не рендерит лишние пиксели |
| Фон | пре-рендер в offscreen-canvas | Градиенты, 3 туманности, 170 звёзд, сетка и виньетка рисуются **один раз** |
| Частицы | ≤ 1200 | Старые вытесняются, кадр не деградирует |
| Ракеты | ≤ 14 (жёстко) | Защита от спама кликами |
| Обломки | ≤ 10 | Самый старый растворяется при переполнении |
| HUD в React | раз в 0.15 с | ~6.7 рендеров/с вместо 60 |
| `dt` | `min(dt, 0.05)` | Возврат из фоновой вкладки не телепортирует физику |
| Пылинки | 28 | Живой передний план почти бесплатно |

### Страховки

- Живая ракета старше **16 с** самоуничтожается — вечное кружение невозможно.
- Всё, что ушло за экран на **200 px**, удаляется.
- `ResizeObserver` + `window.resize` пересобирают фон и зажимают объекты в новые границы.
- `destroy()` отменяет RAF, снимает слушатели, отключает observer и закрывает `AudioContext`.

## 🔊 Звук

Весь звук синтезируется в рантайме — в проекте **нет ни одного аудиофайла**.

| Событие | Синтез |
|---|---|
| Рокот двигателя | Зацикленный шум → bandpass, частота привязана к скорости, громкость — к числу живых ракет |
| Взрыв | Шум с падающим lowpass 3200 → 120 Гц + синус-«бум» 95 → 38 Гц |
| Пуск | Шум через bandpass со свипом 300 → 1700 Гц |
| Двигатель захлебнулся | Sawtooth 420 → 70 Гц + шипение стравливания через highpass |
| Установка / удаление объекта | Короткий square-блип, частота зависит от типа |

Звук **включён по умолчанию**, но `AudioContext` создаётся только после первого клика — так требует политика автоплея браузеров. Один переключатель `🔊 / 🔇` в топбаре глушит **всё** сразу через `master.gain.setTargetAtTime`.

Каждый звук привязан к тому, что видно на экране. Никакого фонового эмбиента-шума.

## 🛠 Решение проблем

| Симптом | Причина и решение |
|---|---|
| `Failed to resolve import "./RocketCanvas"` | Файлы лежат в `src/rocket/`. Импорт: `import RocketCanvas from './rocket/RocketCanvas'` |
| Сцена сжата в центре, по краям отступы | Шаблонные `App.css` / `index.css` от Vite задают `#root { max-width; padding }`. Замени `index.css` сбросом из [Быстрого старта](#-быстрый-старт) |
| Чёрное окно в собранном Electron | Не задан `base: './'`. Под `file://` абсолютные пути `/assets/...` не резолвятся — собирай через `--mode electron` |
| Нет звука | Политикa автоплея: `AudioContext` создаётся после первого клика по сцене. Проверь, что тумблер в топбаре показывает `🔊` |
| Кнопка «Установить» не появляется | PWA требует HTTPS или `localhost`. Проверь `npm run build && npm run preview`, а не открытие файла напрямую |
| Двойная анимация / эхо звука в dev | React StrictMode монтирует эффект дважды. `engine.destroy()` уже отменяет RAF, слушатели и закрывает аудиоконтекст — если правил код, сохрани очистку в `return` эффекта |
| Ракета не догоняет курсор | Так и задумано: манёвренность ограничена. Подними «Манёвренность» или снизь «Скорость» |
| Ракеты не взрываются друг о друга | Проверь тумблер «Ракеты взрываются друг о друга» и увеличь «Ракет одновременно» до 4–6 |
| Цели не уничтожаются в Строителе | Стена прикрывает мишень — ракета тратит себя на первое препятствие. Убери стену ластиком или ПКМ |
| SmartScreen ругается на `.exe` | Нормально для неподписанной самосборки. Код-подпись платная |

## ♿ Доступность и адаптив

- Тумблеры — `role="switch"` + `aria-checked`, режимы — `role="tablist"` / `aria-selected`, тосты — `role="status"`.
- Слайдеры нативные: работают с клавиатуры, фокус виден через `:focus-visible`.
- Хоткеи отключаются при фокусе в полях ввода.
- `prefers-reduced-motion: reduce` отключает въездные анимации панелей и мигание индикатора топлива.
- Кастомный скроллбар панели нарисован в палитре проекта (`scrollbar-color` + `::-webkit-scrollbar-thumb` градиентом), а не системный.
- Брейкпоинты: `900px` — скрывается подзаголовок, `760px` — панель превращается в нижний лист `44vh`, топбар сжимается до иконок, звук остаётся доступен одной кнопкой.
- Все пары текст/фон держат читаемый контраст на всех четырёх палитрах.
